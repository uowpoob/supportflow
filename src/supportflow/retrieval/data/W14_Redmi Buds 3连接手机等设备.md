# Redmi Buds 3连接手机等设备

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 首次蓝牙连接

打开充电盒盖，使左右耳进入待连接状态，在手机蓝牙列表选择Redmi Buds 3。失败时将耳机放回盒内，再重复操作。

来源：[W14 官方文档](https://cdn.cnbj1.fds.api.mi-img.com/ics-resources/articles/6145952075ddeeee2a90fd4b.html)

## 小米快连

耳机放入盒内关盖，靠近已解锁且蓝牙开启的小米手机，再开盖按弹窗连接。快连仅支持部分机型，需兼容的系统稳定版本及小米快连设置。
