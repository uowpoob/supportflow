# 手机不定时重启怎么办

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 第三方应用排查

在开机出现系统标志时按住音量下键，至锁屏界面进入安全模式。若安全模式运行正常，检查近期安装的软件并尝试卸载。入口需与本机系统版本匹配。

来源：[W03 官方文档](https://ics-resources.xiaomi.com/ics-resources/articles/61405ebf6d7f2a110b2a9d03.html)

## 其他排查与送修

检查低温环境和定时开关机设置，更新系统。清除数据应在备份重要资料后进行；仍异常时申请售后检测。
