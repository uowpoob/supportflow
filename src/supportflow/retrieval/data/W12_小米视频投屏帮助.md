# 小米视频投屏帮助

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 发起投屏

在小米视频播放器选择投屏按钮，再选择接收设备。设备支持情况以当前应用和接收端为准。

来源：[W12 官方文档](https://a.video.xiaomi.com/mvideo/screen_help.html)

## 跳集或无法续播

官方帮助指出，电视和手机回报的播放进度或播放状态异常，可能造成跳集和续播问题。先核实播放状态和对应设备，而不能直接将现象判为电视硬件故障。
