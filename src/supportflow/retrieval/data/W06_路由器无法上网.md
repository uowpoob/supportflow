# 路由器无法上网

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 所有设备都无法上网

先检查供电和系统灯，再检查网络灯及WAN网线。升级中的橙灯闪烁应等待完成。灯色因型号不同，不能跨型号直接套用。

来源：[W06 官方文档](https://ics-resources.xiaomi.com/ics-resources/articles/60961933bd1797fb3ecb8740.html)

## 系统正常而网络异常

连接路由器后访问miwifi.com进行诊断，核对PPPoE、DHCP或静态IP配置。将电脑或手机直接接到光猫验证；上级网络也无法访问时联系运营商。重置会影响已有配置，应先保留宽带参数。

来源：[W06 官方文档](https://ics-resources.xiaomi.com/ics-resources/articles/60961933bd1797fb3ecb8740.html)
