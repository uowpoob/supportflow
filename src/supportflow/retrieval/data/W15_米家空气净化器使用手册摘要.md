# 米家空气净化器使用手册摘要

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 安装和滤芯更换

首次开机前去掉滤芯包装膜；为进风预留空间。换滤芯时先关机断电，再按舱内标识装入适配滤芯。

来源：[W15 官方文档](https://cdn.cnbj1.fds.api.mi-img.com/ics-resources/articles/6127640e63e068617e0710bd.html)

## PM2.5读数异常

检查颗粒物传感器舱门是否脏堵，依说明清洁；吹扫不要用热风，清洗的舱门滤网需晾干后装回。水雾可能干扰读数，避免让加湿器水雾进入净化器。
