# 路由器设置静态IP上网失败

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 参数检查

按运营商资料填写IP、子网掩码、网关和DNS。子网掩码需填写完整地址，不能直接填24等前缀长度。

来源：[W10 官方文档](https://ics-resources.xiaomi.com/ics-resources/articles/60961987bd1797fb3ecb8746.html)

## 对照验证

用电脑填写同样参数测试。电脑也无法联网时核对运营商资料；电脑能联网而路由器不能时，按后台选项尝试克隆该电脑MAC地址。

来源：[W10 官方文档](https://ics-resources.xiaomi.com/ics-resources/articles/60961987bd1797fb3ecb8746.html)
