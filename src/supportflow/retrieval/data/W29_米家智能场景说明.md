# 米家智能场景说明

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 条件和动作

场景由触发条件与执行动作组成；传感器可提供条件，灯或扫地机可执行动作，有些设备兼具两类功能。
