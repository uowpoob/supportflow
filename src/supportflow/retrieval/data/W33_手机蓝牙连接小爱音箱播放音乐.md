# 手机蓝牙连接小爱音箱播放音乐

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 开启音箱蓝牙

在小爱音箱应用打开蓝牙开关，或通过语音开启蓝牙。

来源：[W33 官方文档](https://ics-resources.xiaomi.com/ics-resources/articles/60658710b4a57cb035c27bf8.html)

## 连接和播放

打开手机蓝牙，搜索并连接音箱，再在手机播放音乐。Wi-Fi配网和手机蓝牙播放属于不同连接方式，按当前使用方式检查连接。
