# 小米电视故障排查

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 无法开机

分别尝试机身按键和遥控器。仅遥控器失效时检查电池、红外指向或蓝牙状态；二者均失效时换插座验证供电。卡在启动画面时先断电重启。

来源：[W11 官方文档](https://www.mi.com/service/mitv/troubleshooting)

## 应用异常和恢复设置

仅某个应用异常时检查TV适配版本，清理应用数据或重装；检查系统更新。恢复出厂及恢复模式清除数据会丢失设置和数据，应先确认可重新配置，再按本机说明书操作。

来源：[W11 官方文档](https://www.mi.com/service/mitv/troubleshooting)
