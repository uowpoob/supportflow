# 手机或平板耗电快怎么办

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 新机耗电和低温耗电

新机后台同步及应用编译可能暂时增加耗电，先使用观察。低温也可能引起电量跳变或自动关机，移至适宜环境充电后使用。

来源：[W02 官方文档](https://ics-resources.xiaomi.com/ics-resources/articles/6412bcdcb56d1aa766aafb82.html)

## 日常耗电排查

在省电与电池的耗电排行中查看应用消耗；改善网络信号，清理不使用的后台应用，使用自动亮度。应用或菜单路径随系统版本变化，以设备实际界面为准。
