# 小爱音箱控制米家智能设备

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 语音控制前提

音箱和智能设备绑定相同小米账号，且都正常联网。

## 找不到设备或指令

在小爱音箱应用的智能家居页查看账号下支持的设备和可用语音命令。为设备设置房间后，命令可包含房间名称。设备是否支持语音需根据对应型号和应用列表确认。
