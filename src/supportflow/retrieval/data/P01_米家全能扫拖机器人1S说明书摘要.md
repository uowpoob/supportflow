# 米家全能扫拖机器人1S说明书摘要

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 无法开机或充电

先充电，并确认环境在0℃至40℃。检查基座电源两端和主机接触位置，清洁基座与主机充电触点。

来源：[P01 官方文档](https://cdn.cnbj1.fds.api.mi-img.com/iotweb-product-center/b684bffe2cbcf4c001e60603e092c9c4_1663814420834.pdf)

## 配网失败

核对密码，使用2.4GHz网络，让主机处于信号良好区域，再按该型号步骤进入待配网状态。

来源：[P01 官方文档](https://cdn.cnbj1.fds.api.mi-img.com/iotweb-product-center/b684bffe2cbcf4c001e60603e092c9c4_1663814420834.pdf)

## 无法回充

检查基座供电、信号区域脏污及回充路线障碍；必要时将主机手动放回基座。此型号剩余电量需大于15%才启动定时扫拖。

来源：[P01 官方文档](https://cdn.cnbj1.fds.api.mi-img.com/iotweb-product-center/b684bffe2cbcf4c001e60603e092c9c4_1663814420834.pdf)
