# SanDisk 移动固态硬盘 E61 产品规格

（来源：SanDisk 官方网站 Extreme 移动固态硬盘规格页面与产品说明）

本文档收录 SanDisk 移动固态硬盘 1TB（型号 E61）的读写性能、防护能力、加密功能、出厂格式与常见问题处理。

## 容量与性能

容量 1TB。接口为 USB 3.2 Gen 2（10Gbps），官方标称顺序读取速度最高 1050MB/s，顺序写入速度最高 1000MB/s。实际速度受主机接口、文件类型和系统缓存影响，拷贝大量小文件时速度会明显低于标称值。

要跑出标称速度，主机的接口必须是 USB 3.2 Gen 2 或更高规格。接在 USB 3.0（5Gbps）接口上速度上限约为 450MB/s；接在 USB 2.0 接口上速度会掉到几十 MB/s。

## 外壳与防护

具备 IP65 防护等级，可完全防尘，并可在低压喷水条件下短时间使用。官方标称可承受约 2 米高度的跌落。机身尺寸约 100.5 x 52.4 x 8.95 毫米，重量约 39 克，带挂绳孔。

IP65 只针对固体与喷水，不表示可以浸泡。请不要将硬盘长时间浸入水中，也不要带到海水环境后不冲洗。跌落防护是在实验室条件下测得，多次跌落后即使外观完好，内部也可能已经损伤。

## 硬件加密

支持 AES 256 位硬件加密，安装并运行随盘的管理软件后可以设置密码，密码启用后每次接入都需要解锁。加密是硬件层面的，即使拆出内部闪存也无法绕过。

密码一旦遗忘无法找回，也无法由官方重置，数据将永久无法读取。请在启用加密前自行做好重要数据的另一份备份。

## 出厂格式与跨平台使用

出厂格式为 exFAT，Windows 与 macOS 都可以直接读写，无需格式化。如果要把硬盘作为 Mac 的时间机器（Time Machine）备份盘使用，需要先格式化为 APFS 或 Mac OS 扩展格式，格式化会清空盘中所有数据。

在 Windows 上格式化过的 NTFS 盘在 macOS 上默认只能读取不能写入，需要在 macOS 上安装额外驱动或者改格式。

## 随附配件

随附一条 USB-C 转 USB-C 数据线和一只 USB-C 转 USB-A 转接头。转接头用于连接老式 USB-A 接口，但转接头本身会限制速率，使用转接头时速度会明显低于直连 USB-C。

## 使用与保养

硬盘工作时内部温度会升高，金属外壳兼作散热，温热属于正常。长时间大量读写后烫手时应暂停使用，让硬盘自然冷却。

务必使用「安全删除硬件」或者系统的推出功能断开硬盘，直接拔线可能造成正在写入的数据损坏。移动硬盘正在读写时不要晃动或搬动。

避免把固态硬盘长期插在电脑上当作系统盘使用，移动固态硬盘的散热条件不如内置硬盘，长期满载会加速老化。

## 常见问题与处理

电脑识别不到硬盘：更换数据线并直接接入主机后置 USB 口，不要通过劣质扩展坞转接；在其他电脑上测试以判断是硬盘还是主机问题；确认硬盘指示灯是否亮起。

速度远低于标称值：确认主机接口为 USB 3.2 Gen 2 及以上；确认没有使用 USB-A 转接头；确认拷贝的是大文件而不是大量小文件；确认系统没有同时进行其他大量读写。

读写过程中断开：检查线材与接口是否松动；排查是否因供电不足（常见于通过扩展坞或前面板接口连接）；若换线换口后仍频繁断连，停止使用并联系售后，避免继续写入造成数据损坏。

文件在 Mac 上能读不能写：这是 NTFS 格式的限制，需要在 Mac 上安装读写驱动，或者把盘重新格式化为 exFAT、APFS。

忘记加密密码：官方无法找回也无法重置，数据无法恢复。这是硬件加密的设计要求，不是产品缺陷。

外壳有划痕或掉漆：金属外壳在频繁携带中产生磨损属于正常使用痕迹，不影响功能。
