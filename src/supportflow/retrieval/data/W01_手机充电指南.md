# 手机充电指南

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 日常充电

锂电池无需进行消除记忆效应的充电操作，可以随用随充。优先使用原装充电器，避免长期耗尽电量。

来源：[W01 官方文档](https://ics-resources.xiaomi.com/ics-resources/articles/60501b525078534fd762175a.html)

## 温度与充电异常

官方指南给出的适宜电池工作温度为10℃至35℃。过冷可能无法充电或续航缩短；过热可能充电变慢、充不满或自动关机。先改善使用环境，再观察充电状态。具体温度要求以本机说明书为准。
