# 罗技 K380 键盘 产品规格

（来源：罗技官方网站 K380 多设备蓝牙键盘产品页面与使用说明）

本文档收录罗技 K380 多设备蓝牙键盘的连接方式、键位布局、续航与常见问题排查方法。

## 基本规格

薄膜按键键盘，键位采用圆形键帽设计。按键行程较短，敲击声音较小。机身尺寸约 279 x 124 x 16 毫米，重量约 423 克。使用两节 AAA 电池供电，官方标称续航约 24 个月。

## 多设备连接

最多可同时配对 3 台设备，通过键盘上方的三个 Easy-Switch 通道键在设备之间切换。通道键分别对应 1、2、3 号设备，按下后指示灯亮起即可在该设备上输入，切换过程无需重新配对。

支持 Windows、macOS、iOS、iPadOS 与 Android 系统。长按对应通道键可以重新进行配对。

## 蓝牙规格与连接范围

蓝牙 3.0 版本，有效连接距离约 10 米，实际距离受墙体、机箱金属和无线干扰影响。

键盘没有 USB 接收器，只能通过蓝牙连接。如果主机没有蓝牙或者蓝牙不稳定，K380 无法使用。

## 键位布局与切换

键盘内置 Windows 与 macOS 两套键位布局，通过 Fn 键加对应按键切换。切换到 Mac 布局后，Command 键位置与 Mac 键盘一致；切换到 Windows 布局后恢复为 Ctrl 与 Win 键。

键盘没有独立的方向键区与数字键盘，方向键通过 Fn 组合键实现，长时间使用表格类软件时会不太方便。

## 使用与保养

键帽之间容易积存灰尘和碎屑，可以用软毛刷或者低档位吸尘器清理，也可以用气吹吹出缝隙中的杂质。不要用湿布直接擦拭按键缝隙，液体渗入会造成短路。

电池仓在键盘背面。长期不用时建议取出电池，避免电池漏液腐蚀电路。更换电池后需要重新开关一次电源开关以唤醒键盘。

键盘不具备防水能力，请避免在键盘附近放置水杯，液体洒落后应立即断电、取出电池并倒置晾干，切勿通电测试。

## 常见问题与处理

蓝牙搜不到键盘：长按目标通道键约 3 秒进入配对模式，此时对应通道的指示灯快速闪烁；指示灯常亮说明键盘正在回连上一次的设备，需要在旧设备上删除配对记录，否则键盘会优先连回旧设备；确认键盘电源开关已打开。

配对成功但输入延迟或有丢字：确认键盘与主机距离在 10 米以内；靠近主机使用排除信号问题；检查是否有其他蓝牙设备占用带宽；更换主机的蓝牙适配器或者减少周边 2.4GHz 设备。

按键错乱，输入的字符与键位不符：键盘处于另一套系统的键位布局，按 Fn 加对应的系统切换组合键切回；确认系统语言与键盘布局设置正确。

某个通道无法切换：确认该通道已经完成配对；长按通道键重新配对；删除其他设备的配对记录后重试。

无法开机或指示灯不亮：更换两节新 AAA 电池；确认电池正负极方向正确；用干布擦拭电池仓触点，清除氧化层。

切换到 Mac 后音量键、亮度键失灵：部分功能键需要系统允许辅助功能权限，或在系统偏好设置中把功能键行为改为标准功能键，属于系统层面设置，不是键盘故障。
