# 小米手环如何绑定

本文为官方资料的简明摘要；型号、按键、菜单及故障码应与对应设备核对。完整信息见官方来源或原始说明书。

## 选择绑定应用

手环2至4使用Zepp Life；5至7系列可使用小米运动健康或Zepp Life；7 Pro、8及来源列出的8系列版本使用小米运动健康。不能同时绑定多个应用。

来源：[W13 官方文档](https://cdn.cnbj1.fds.api.mi-img.com/ics-resources/articles/5b4867f6cc25ef916398d927.html)

## 搜索和重新绑定

在应用设备页添加对应型号，核对蓝牙地址并在手环确认。无法发现时按本机指引恢复后重新添加；恢复或解绑会重置手环。iOS重新绑定前，在系统蓝牙中忽略旧设备。
