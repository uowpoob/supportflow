# 绿联 Type-C 数据线 2m 产品规格

（来源：绿联官方 Type-C to Type-C 100W 快充数据线产品说明与线材实测资料）

本文档收录绿联 Type-C 转 Type-C 100W 快充数据线（2 米）的规格、功率与协议支持、适用场景和使用注意。

## 基本规格

线长为 2 米，两端均为 Type-C 公头。线身直径约 4.24 毫米，重量约 70 克。外壳为铝合金或注塑一体式设计，网尾与接头一体成型，表面磨砂处理，便于插拔。

## 功率与协议支持

支持 20V/5A，即最高 100W 的 PD 快充功率。线材内置 E-Marker 电子标签芯片，通过 CC 通讯向供电端声明自身的电流承载能力，供电端据此决定协商的档位。没有 E-Marker 的线材在 5A 场景下会被限制到 3A。

兼容 PD 3.0 协议，支持 PPS 档位的设备也可正常使用。可搭配 65W、100W 等功率的 PD 充电器为笔记本、手机、平板和移动电源快充。

## 数据传输能力

数据传输规格为 USB 2.0，理论速率 480Mbps。这条线定位是充电线，不是高速数据线，不适合外接固态硬盘、视频采集或者显示扩展。需要传大文件或者连接显示器时，应选择标注 USB 3.2 或雷电规格的线材。

线材不带视频输出能力，不能用作 DisplayPort Alt Mode 显示器连接线。

## 线材结构

内部采用多股加粗镀锡铜线芯，正极电力线芯为双线并联以降低电阻。线身包含编织屏蔽网与屏蔽铝箔两层结构，并填充抗拉线增加强度。插座端插头点焊不锈钢外壳，并用硬胶填充加固。

## 适用场景

适合把 2 米线接在离插座较远的桌面使用，或者放在沙发边、床头给手机充电。2 米长度在同样功率下比 1 米线有更大的压降，因此对线材用料要求更高，这条线在 20V/5A 档位实测压降约 0.84V，属于可接受范围。

## 使用注意

插拔时抓接头而不是拉线身，避免内部线芯受拉损伤。长期把线材弯折成锐角、压在桌腿下或者被椅子滚轮碾过，都会造成内部断芯，表现为某个角度能充、换个角度就断。

不要把线材长时间暴露在阳光直射或者高温环境中，护套会加速老化开裂。清洁时用干布擦拭，不要用酒精浸泡。

## 商品页型号标注说明

商品页面上标注的型号串为「CD137 100W」。绿联官方型号命名中 CD137 对应的是充电器产品，数据线本身在官方体系里以「Type-C to Type-C 100W 快充数据线」这一类目名销售。核对型号时以商品页截图和订单记录为准，不必以型号串与品牌官网逐一对应。

## 常见问题与处理

充电速度达不到标称瓦数：确认充电器支持 PD 且功率足够；确认被充设备支持快充；确认线材两端都插到底。可以用带功率显示的测试仪串在中间查看实际协商到的电压电流。

时而能充时而不能充：多为接头内部虚焊或者线芯断裂，尝试在不动线材的情况下缓慢改变线材角度，若现象随角度变化即可判断为线材故障，需要更换。这类损伤通常不在保修范围内，属于使用损耗。

给笔记本充电提示功率不足：确认充电器功率不低于笔记本要求的档位；确认线材为 USB-C 到 USB-C 全功能线；部分笔记本需要 100W 以上才能满速供电，65W 只能维持慢速充电。

连接固态硬盘或显示器不识别：这条线只支持 USB 2.0 数据，且没有视频输出能力，需要改用对应的数据线或视频线。
