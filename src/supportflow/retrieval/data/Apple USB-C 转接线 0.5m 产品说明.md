# Apple USB-C 转接线 0.5m 产品说明

（来源：Apple 中国官网 USB-C 连接线与转换器产品页面）

本文档说明 Apple USB-C 转接线（0.5 米）的产品形态、接口组合、兼容范围与选购核对要点。

## 产品定位

这是一根 0.5 米的短款转接连接线，用于在 USB-C 接口的主机与 Apple 配件之间做接口转换，也常用于随身携带的短距连接场景。长度短、便于收纳，但使用距离受限，接在机箱后面的接口上往往够不到桌面。

## 常见接口组合

Apple 官方的 USB-C 短线主要有两种形态：USB-C 至 Lightning 连接线，用于给采用 Lightning 接口的 iPhone、iPad 和 AirPods 充电盒连接 USB-C 电源或电脑；USB-C 至 USB-A 转换线，用于把 USB-A 外设接到 USB-C 接口的主机上。

两种线外观相似，功能完全不同，不能互换使用。识别方法是看两端的接口形状：一端是扁圆形 Lightning 接口，另一端是椭圆形 USB-C 接口。

## 兼容范围

USB-C 至 Lightning 连接线兼容采用 Lightning 接口的 iPhone、iPad、iPod touch 与 AirPods 系列。用于充电时支持 USB PD 快充，用于连接电脑时需要搭配 iTunes 或访达完成同步。

USB-C 至 USB-A 转换线支持 USB 2.0 数据传输速率，用于连接键盘、鼠标、U 盘等 USB-A 外设，也可以给 USB-A 设备充电，但输出电流受主机接口限制。

## 型号核对要点

商品页只标注了长度与「USB-C 转接线」，未区分具体接口组合。核对实物时应以接头形状为准，两个接口形状不同的才是转接线，两端都是 USB-C 的是普通 USB-C 连接线。遇到售后争议时，以订单页面的商品型号串与实物照片共同判定。

## 使用注意

短款线材弯折半径小，插拔时容易抓着线身发力，长期如此会造成接头处内部断芯。正确做法是抓接头外壳拔出。

线材不支持视频输出，不能用于连接显示器。需要外接显示器时应选择支持 DisplayPort Alt Mode 的 USB-C 视频线或使用转换器。

## 常见问题与处理

插上后不识别设备：确认接口插入到底；确认线材的接口组合与设备匹配，Lightning 线与 USB-A 转换线的用途不同；更换主机上的另一个接口测试；用其他线材交叉验证以判断是线还是设备的问题。

充电速度慢：短线材通常只支持 USB 2.0 与基础功率，给 iPad 或笔记本充电时功率可能不足；确认搭配的电源适配器功率足够。

电脑提示「无法识别此配件」：清理接口内的灰尘与棉絮；确认触点无氧化发黑；若线材有过弯折损伤，请更换线材。

连接后数据传输中断：多为接头接触不良或线材内部断芯，轻微改变线材角度即可复现，属于使用损耗，需要更换线材。
